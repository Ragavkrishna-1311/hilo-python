# Bubble Sort in Python

A simple implementation of the Bubble Sort algorithm using Python.

## How it works

Bubble Sort repeatedly compares adjacent elements and swaps them
when they are in the wrong order.

## Complexity

- Time: O(n²)
- Space: O(1)

python main.py
